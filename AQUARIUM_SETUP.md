# Aquarium Scene Setup

To complete the aquarium scene, you need to download the GLTF models from the CodeSandbox.

## Required Files

Download these files from the CodeSandbox (https://codesandbox.io/p/sandbox/n7jf0f) and place them in the `static` folder:

1. **shapes-transformed.glb** - The glass aquarium tank model
2. **model*52a*-\_kemps_ridley_sea_turtle_no_id-transformed.glb** - The animated turtle model

## Steps:

1. Open the CodeSandbox: https://codesandbox.io/p/sandbox/n7jf0f
2. In the file tree, locate the `public` folder
3. Download both `.glb` files
4. Place them in `/Users/martaballardini/Desktop/labday23:10/my-svelte-app/static/`

## Optional: HDR Environment Map

For better reflections, you can also add an HDR environment map:

- Create a folder: `static/hdr/`
- Download an HDR file from https://polyhaven.com/hdris
- Place it in the `hdr` folder

Once the files are in place, refresh your browser and you should see the glass aquarium with the swimming turtle and floating bubbles!
